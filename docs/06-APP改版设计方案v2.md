# 思维赋能 · 教研会议 APP 改版设计方案 v2

> 本文档供评审修改。请在各节直接批注或改字，确认后按此实施。
> 现状：uni-app(Vue3) + Spring Boot(mind-mobile) + MySQL + Neo4j，已完成会议/批注/投票/学情基础功能。

---

## 1. 改版目标

1. **更简洁**：三个 Tab 收成一个"工作台"首页，减少层级；一个会议一个页面做完所有事。
2. **更完整**：从"开会工具"升级为"教研闭环工具"——会前（通知/材料）→ 会中（批注/投票/讨论）→ 会后（纪要/待办/沉淀）。
3. **更好用**：老师 3 分钟内发起会议，成员扫码进会，会后自动生成纪要。

## 2. 用户角色

| 角色 | 说明 |
|---|---|
| 主持人（组长） | 创建会议、上传教案、发起投票、分配待办、结束会议 |
| 参会教师 | 加入会议、圈画批注、讨论、投票、领取/完成待办 |
| 学生（二期） | 仅学情端，不进会议 |

## 3. 功能架构（改版后）

```
首页（工作台）
├── 快捷操作：发起会议 / 扫码加入（一个大按钮 + 一个图标按钮）
├── 我的会议（卡片流：进行中置顶，时间线排期）
├── 待办（红点数提醒，会议里分配的任务聚合）
└── 最近动态（我收到的批注回复、投票结果、任务提醒）

会议页（单页整合，顶部页签）
├── 教案（上传/查看/手绘批注/AI 解析/量化评审）
├── 讨论（群聊）
├── 批注（列表+回复+已解决）
├── 投票（发起/投票/结果）
└── 成员（在线状态/主持人管理）
└── 会后自动生成：会议纪要 + 待办清单

学情
├── 班级掌握度热力图
├── 知识点维度分析（点击热力图格子 → 该知识点全班详情）
└── 学生个人画像（二期）

我的
├── 个人资料、我的证书/荣誉（二期）
├── 会议纪要历史
├── 服务器设置 / 清除缓存 / 退出登录
```

**砍掉的**：创建会议单独页 → 收进首页底部弹层（主题+学科+议程三步）；加入会议页保留但可从首页直达。

**新增的（本期做）**：
1. **会议纪要**：会议结束时，汇总讨论要点、批注结论、投票结果，生成结构化纪要存到"我的-纪要历史"，可导出分享。
2. **待办闭环**：主持人在批注/讨论里长按 → "转为待办"指派给某人+截止时间；首页待办角标聚合，完成打勾。
3. **会议通知**：被邀请后首页出现会议卡，临近开始（15 分钟）红点提醒。
4. **教案库**：上传过的教案在"我的-教案库"留存，可复用到新会议，不用每次重传。

**新增的（二期，先留接口）**：
5. 听评课打分表（量表化评分：教学目标/环节设计/学生活动…）
6. 教师成长档案（参与会议数、批注数、获赞数）
7. 学生端学情查看

## 4. 页面与导航设计（简洁化）

**底部 Tab 从 3 个改为 2+1 个**：
- 「会议」（默认页 = 工作台）
- 「学情」
- 「我的」

首页结构（从上到下）：
```
[搜索/扫一扫]                ← 顶栏
[＋ 发起教研会议]            ← 唯一主按钮，全宽翠绿
[进行中] 会议卡（可点击进入）
[即将开始] 会议卡 ×n
[待办] 行入口（角标=未完成数）
[最近动态] 3-5 条信息流
```

**会议卡设计**（替代现有三页签列表）：
- 左：学科色块圆角标（化=绿、数=蓝…）+ 标题 + 时间
- 右：状态（进行中绿点呼吸 / 待开始灰 / 已结束浅灰）+ 主持人头像
- 点击整卡进会议页；进行中的卡右上角显示"讨论 n 条新消息"

**会议内页签整合**：保留现有 5 页签，但默认落在"讨论"（进会先看大家说什么），教案批注红点提醒。顶部信息栏压缩成一行（标题滚动 + 状态点）。

## 5. UI 设计规范（简洁方向）

- **信息密度**：每屏一个核心任务，次要操作收进"⋯"
- **色彩**：主色翠绿 #00B578 只用于主按钮和关键状态；头部去色（白底黑字，仅会议中页用深绿头部）；学科色仅用于色块标识
- **卡片**：圆角 16rpx、无阴影、灰底 #F4F5F7 衬白卡
- **字体**：标题 600 字重不加粗过度，正文 #191919，辅助 #999
- **图标**：线性图标统一 2rpx 描边，不用 emoji 当功能图标（emoji 仅作内容点缀）
- **空态**：每页统一空态插画 + 一句引导文案 + 一个操作按钮

## 6. 关键交互流程

**发起会议（3 步弹层）**：
首页点主按钮 → 底部弹层 ① 填主题（必填）+ 选学科 → ② 选议程类型 → ③ 选参会人（默认全组）→ 创建成功直接进会议页，弹toast显示会议号可复制。

**加入会议**：
首页扫一扫（调相机扫二维码）或点"输码加入"→ 6 位点阵输入 → 直达会议页。

**会中转待办**：
讨论/批注条目长按 → 弹层"转为待办"→ 选人 + 选截止时间 → 对方首页待办出现红点。

**会后纪要**：
主持人点"结束会议"→ 弹窗"生成会议纪要？"→ 确认后后端聚合（讨论高频词、已解决批注、投票结果、待办清单）生成纪要 → 存"我的-纪要历史"，所有成员可见。

## 7. 技术架构（不变，扩展）

```
移动端  uni-app Vue3（一期仅 Android APK + H5）
后端    Spring Boot 多模块，新增 mind-meeting 业务聚合层
数据库  MySQL：会议/批注/投票/待办/纪要/教案库 6 类表（在现有 8 表上扩展）
图谱    Neo4j：知识点图谱（量化评审用，接口不变）
通知    轮询+红点（一期）→ 离线推送（二期，UniPush）
```

**本期新增接口（约 10 个）**：
- POST /api/mobile/minutes/generate 生成纪要
- GET  /api/mobile/minutes/list|detail 纪要列表/详情
- POST /api/mobile/task/fromAnnotation 批注转待办
- GET  /api/mobile/notice/recent 最近动态
- GET  /api/mobile/document/library 教案库
- POST /api/mobile/meeting/{id}/remind 会议提醒
- 其余复用现有

## 8. 数据库改动（在现有 8 表基础上）

- `meeting_minutes`（新）：纪要 id、会议 id、内容 JSON、生成时间
- `meeting_task`（扩展）：加 source_type/source_id（来自哪条批注/讨论）、assigner_id（指派人）
- `document`（扩展）：加 uploader_id、library 字段（是否入教案库）
- `meeting_notice`（新）：动态流（批注回复/投票/任务 三类事件）
- 其余表不动

## 10. 需要你拍板的问题

1. 首页主按钮是"发起会议"还是"扫码加入"？（我倾向发起会议）
2. 纪要自动生成要不要接大模型润色？（接：更通顺；不接：纯模板聚合，快且稳）
3. 学科色块标识要不要做？（做的话需要一套 9 科配色）
4. 二期里听评课打分表优先还是教师成长档案优先？
5. 已结束的会议是否允许回看全部内容（讨论/批注/投票）？（我建议允许，作为教研档案）
