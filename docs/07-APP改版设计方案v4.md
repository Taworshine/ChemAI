# 思维赋能 · 教研 APP 改版设计方案 v4

> v4 在 v3 基础上新增两大模块：**教案中心**、**题库（错题+习题）**，知识图谱构建与桌面端系统保持同一套 Neo4j 图谱。
> 延续 v3 的设计原则：每屏一个主按钮、三段式页面、命名说人话、状态一眼可见。

---

## 1. 本版新增能力总览

```
教案中心                          题库
├─ 教案库（上传/结构化/管理）        ├─ 错题本（拍照录入 → AI 分析）
├─ 教案体检（图谱比对，原量化评审）   ├─ 习题库（录入 → 知识点标注）
└─ 教案关联（挂错题/挂习题/挂会议）   └─ 学情热力图（错题数据反哺）
```

**知识图谱构建（与本地桌面系统同一套 Neo4j）：**
- 节点：知识点（如"卤代烃的消去反应"）、题型、错因、题目（错题/习题）
- 关系：知识点-包含→知识点；题目-考查→知识点；错题-错因→错因标签；知识点-前置→知识点；教案-覆盖→知识点
- 三条构建流水线，共用桌面端的图谱写入服务：
  1. **教案解析**：docx 教案 → 抽取课题/考向知识点 → 写入/对齐图谱节点 → 计算覆盖度
  2. **错题分析**：拍照 → OCR+大模型识别题干 → 抽知识点+错因 → 挂图谱 → 计入班级薄弱点
  3. **习题标注**：录题 → 自动标注考查知识点（可人工纠正）→ 入图谱 → 支持按知识点组卷

## 2. 底部导航（4 个 Tab，一屏一件事）

| Tab | 名称 | 内容 |
|---|---|---|
| 1 | 会议 | 首页：发起/扫码 + 会议卡流 + 会后任务 |
| 2 | 教案 | 教案库 + 教案详情 + 教案体检 |
| 3 | 题库 | 错题本 + 习题库 + 学情热力图 |
| 4 | 我的 | 资料卡 + 纪要/设置/退出 |

> 学情热力图收进「题库」顶部入口：错题数据天然驱动学情，比单独一个 Tab 更顺。

## 4. 教案 Tab 设计

### 4.1 教案库（列表页）

```
┌──────────────────────────────┐
│ 教案                    ＋上传 │  ← 顶栏：标题+右上角上传
├──────────────────────────────┤
│  高三化学 · 8 份  ▾          │  ← 一行筛选条：学段学科下拉
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 官能团的性质——卤代烃      │ │  ← 教案卡
│ │ 有机化学 · 第2周 · 2课时  │ │
│ │ 体检 92 分      已关联 3 题 │ │  ← 一行数据：体检分+关联
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 官能团-醇酚性质            │ │
│ │ 体检 78 分  ⚠ 2 个薄弱点  │ │  ← 体检差的突出提醒
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

**规则**：一张卡 = 一份教案；卡片上只放"名字+位置信息+体检结果"三行，其他全部进详情。

### 4.2 教案详情（新页面，替代"看图"）

上传 docx 后后端**按表单结构解析**，手机端呈现为结构化卡片而不是一张图：

```
┌──────────────────────────────┐
│ ‹ 官能团的性质——卤代烃        │
│ 有机化学 · 第2周 · 王老师    │
├──────────────────────────────┤
│ [教案内容]                    │
│ 教学目标：认识卤代烃组成…      │  ← 折叠块：点标题展开
│ 教学重难点：消去反应条件      │
│ 教学过程：一、卤代烃的化学性质 │
│ 板书设计：（图）              │
│ 教学反思：（空）              │
├──────────────────────────────┤
│ [教案体检] 92 分              │  ← 整块可点进体检详情
│ 覆盖 12 个知识点 · 缺 1 个     │
├──────────────────────────────┤
│ [关联] 错题 2 道 · 习题 5 道   │  ← 整块可点管理关联
└──────────────────────────────┘
```

### 4.3 教案体检（原量化评审，改名+简化）

只保留一张**体检报告单**式页面，四段固定结构：
1. **总评**：环形总分 + 一句话结论（"本教案覆盖良好，建议补充消去反应与取代反应的对比"）
2. **覆盖了什么**：知识点 chips（绿）
3. **缺什么**：缺失知识点 + 建议补充的教学环节（红/橙）
4. **风险预判**：学生可能遇到的思维误区（来自图谱的 misconception 节点）

### 4.4 关联管理（一个弹层）

教案详情点"关联"→ 弹层搜索错题/习题库 → 勾选挂到本教案 → 图谱中建立 `教案-覆盖→知识点` 之外的 `教案-使用→题目` 关系。

## 5. 题库 Tab 设计

顶部一行三段切换（错题 | 习题 | 学情），下方共用内容区。

### 5.1 错题本

```
┌──────────────────────────────┐
│ 题库                  📷 录错题 │  ← 主按钮在右上，列表保持干净
├──────────────────────────────┤
│  错题 | 习题 | 学情           │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ [图] 卤代烃消去反应条件   │ │  ← 错题卡：缩略图+一句话
│ │ 错因：条件混淆 · 3 人错   │ │  ← 关键数据：错因+错误人数
│ │ 考查：卤代烃的消去反应    │ │
│ └──────────────────────────┘ │
```

**录错题流程（3 步）**：
1. 拍照/相册选图（可一道可多道）
2. AI 识别：显示识别出的题干 + **考查知识点（图谱自动匹配，可改）** + **错因标签**（条件混淆/概念不清/计算错误…可改）
3. 确认入库 → 自动写图谱 → 班级学情同步更新

### 5.2 习题库

- 录入：手动录 / 拍照录（同错题流水线，但无"错因"，多"难度"）
- 每道习题卡片：题干摘要 + 考查知识点 + 难度 + 被哪些教案/试卷用过
- 组卷：按知识点勾选 → 生成练习卷（二期导出 Word）

### 5.3 学情（热力图，v3 设计不变）

- 图上方一行班级信息；图下方只留一个洞察条：**"本班薄弱点：消去反应条件、酯化反应方程式"**（从错题图谱自动聚合）
- 点格子弹层看该知识点的错题列表

## 6. 图谱数据流（与桌面端一致）

```
教案 docx ──解析──→ 考向知识点 ──┐
错题 拍照 ──OCR+LLM─→ 知识点+错因 ├→ 图谱对齐服务（共用）→ Neo4j
习题 录入 ──LLM────→ 考查知识点 ──┘        ↓
                                    教案体检 / 学情热力图 / 薄弱点洞察
```

- 复用桌面端已有的图谱节点 Schema 和写入接口，移动端只做采集和展示
- 图谱里每个知识点节点挂：**教案覆盖数、错题出现次数、习题出现次数** 三个属性，移动端所有页面都从这三个属性取数

## 7. 命名规范（在 v3 基础上补充）

| 不叫 | 统一叫 |
|---|---|
| 量化评审 | 教案体检 |
| 错题录入 | 录错题 |
| 上传教案 | 上传教案（不变） |
| 知识点标注 | 考查知识点 |
| 薄弱点 | 薄弱点（图谱聚类结果） |

## 8. 数据库/接口增量

**新表 3 张**：
- `wrong_question`：错题（图、题干 OCR、知识点 id、错因标签、录入人、班级、出现人数）
- `exercise`：习题（题干、答案、难度、知识点 id、来源）
- `plan_link`：教案-题目关联（教案 id、题目 id、类型）

**新接口约 12 个**（解析/识别走桌面端已有服务，移动端只做转发）：
- 教案：library 列表/详情/上传/删除、体检报告、关联增删
- 题库：错题拍照上传+AI 分析确认、错题列表、习题录入/列表、学情薄弱点聚合
