# 思维赋能 · 教研 APP 改版设计方案 v5（整体结构 + 高级个人中心）

> v5 = v4 的功能范围（会议 / 教案 / 题库 / 学情 / 图谱）+ 重新设计的整体页面结构 + 高级版个人中心。
> 目标：打开 APP 有"专业工具"的质感，不是 demo。每页克制、留白充足、数字有层次。

---

## 1. 整体页面结构

```
底部 4 个 Tab
┌─────────┬─────────┬─────────┬─────────┐
│  会议    │  教案    │  题库    │  我的   │
│ (首页)   │         │         │ (个人中心)│
└─────────┴─────────┴─────────┴─────────┘

10 个页面：
P1 会议首页    P2 会议现场   P3 会议纪要   P4 加入会议
P5 教案库      P6 教案详情   P7 教案体检
P8 题库(错题/习题/学情)      P9 录错题(拍照流程)
P10 我的(个人中心) + 二级页：纪要列表 / 我的教案 / 消息通知 / 设置
```

## 2. 视觉体系（高级感来源）

**色彩（克制用色）**
- 品牌翠玉绿 `#00B578`：只出现在主按钮、Tab 选中、关键数据
- 深墨绿 `#0F5C46`：仅用于会议现场的沉浸头部
- 页面背景 `#F6F7F9`（比纯灰更冷的微蓝灰），卡片纯白
- 文字三级：标题 `#191919` / 正文 `#4E5969` / 辅助 `#86909C`
- 学科色块：9 科各一色，仅小圆角方块使用，不大面积铺色

**质感三要素**
1. **数字放大**：关键数据用 44-64rpx 细体大字（如体检 92 分、待办 3），标签小字，形成层次
2. **卡片呼吸**：卡片内边距 32rpx，卡片间距 20rpx，圆角统一 20rpx，无阴影只用 1rpx 描边 `#F0F0F0`
3. **图标线性化**：全部 2rpx 描边线性图标（uni-icons），emoji 只出现在内容里，不当功能图标

**动效（轻）**
- 页面进入：内容区 150ms 上移淡入
- 按钮按压：缩放 0.97 + 颜色加深
- 数据加载：骨架屏（卡片灰色占位条），不用转圈 loading

**个人中心设计要点**：
- 头部不用白卡，用深墨绿渐变（和品牌绿同族），一打开"我的"就有辨识度
- 三格数据条把"数字放大"原则用到个人数据上，让老师有积累感
- 菜单按「我的工作 / 数据中心 / 系统」三组，每组 3-4 项，组间距明显，不拥挤
- 每个二级页都是同一套版式：顶部大标题 + 列表/卡片流，不再出新花样

### 3.5 会议现场（沿用 v3/v4，质感升级）

- 深墨绿沉浸头部 + 白底页签栏，页签文字选中加粗不加色块
- 讨论气泡沿用薄荷绿；圈画笔色条悬浮收起
- 主持人"⋯"菜单收纳：暂停加入 / 请出成员 / 结束会议 / 生成纪要

## 4. 高级感的细节清单（实施时逐条落实）

| 位置 | 细节 |
|---|---|
| 全局 | 数字统一 DIN 风格细体，金额/分数类 1.2 倍行高 |
| 首页 | 问候语按时段变化（早上好/下午好/晚上好） |
| 卡片 | 全部 20rpx 圆角 + 1rpx 描边，禁止阴影 |
| 列表行 | 统一 96rpx 行高，图标 20px 线性，右侧 › 箭头 |
| 空态 | 统一插画风格（线性+品牌绿点缀）+ 一句引导 |
| 加载 | 骨架屏，内容区灰色占位条 |
| 成功反馈 | 绿色 toast + 内容区局部刷新，不整页跳 |
| 头像 | 姓氏单字 + 学科色背景（化=绿 数=蓝 物=紫…） |
