# 思维赋能 · 高中全学科智能教学辅助系统 —— 功能与操作手册

> 版本：v1.0（2026-10-26） · 适用系统版本：P1–P5 全部交付版
> 配套设计文档：`docs/05-上传抽取与教师确认设计方案.md`（v1.4）

---

## 一、系统简介

本系统是一个以 **Neo4j 知识图谱为核心**、以大模型为增强引擎的高中全学科教学辅助系统，覆盖语文、数学、英语、物理、化学、生物、历史、地理、政治九大学科。

**业务主线**：

```
教师备课资料（教案/讲义/知识点）
   → 上传 → 大模型抽取 → 教师逐条确认（防重复）
   → 写入 Neo4j 知识图谱 → 发布上线
   → 学生练习 / 智能追问 / 高频问题
   → 学情数据回流 → 教研看板 / 缺口反哺下一轮备课
```

核心原则：**大模型只提候选，教师点头的才进图谱；学生只用"已发布"的内容；学情数据回流反哺备课**。

## 二、运行环境与启动

| 服务 | 端口 | 说明 |
|---|---|---|
| Neo4j | 7687 / 7474 | 图数据库（浏览器控制台 http://localhost:7474） |
| MySQL | 3306 | 业务库 `mind_empower` |
| Java 后端 | 8080 | Spring Boot（业务 API） |
| Python AI 服务 | 8000 | FastAPI（大模型抽取/聚类/对话） |
| 前端 | 5173 | Vite 开发服务器 |

启动顺序（首次或数据被清空前，先导入数据）：

```
1. init-sql.bat      ← 建 MySQL 表（幂等，可重复执行）
2. import-data.bat   ← 导入 Neo4j 种子数据（幂等）
3. start-all.bat     ← 一键启动 后端 + AI 服务 + 前端
4. stop-all.bat      ← 一键停止全部服务
```

访问地址：**http://localhost:5173**

## 四、教师端功能与操作

登录后默认进入「工作台」。侧边栏共 10 个入口，其中「资源管理」「教研中心」为下拉分组。

### 4.1 工作台（/teacher/dashboard）

- 顶部数据概览（5 项）：在校学生、图谱知识点、教学文档、题库题目、练习次数；
- 快捷入口卡片：跳到编辑知识图谱等高频页面；
- 「教研中心」菜单项带**红色待办徽标** = 待确认任务数 + 待解答问题数（60 秒自动刷新，为 0 时不显示）。

### 4.2 知识图谱（/teacher/graph）

- **3D 力导向图谱**：滚轮缩放、拖拽平移、点击节点展开/收起其关联节点；
- 初始只显示关键核心节点，点击任意节点后以它为中心发散（带碰撞布局动画）；
- 点击节点弹出**溯源信息**：来源教案/上传教师/入库时间/任务状态/一跳关系摘要（种子节点显示「系统预置知识点」）；
- 顶部支持按学科、年级筛选；「聚焦模式」开启后点击节点会把无关节点淡出为浅灰。

### 4.3 知识管理（/teacher/knowledge）

图谱节点的**后台管理系统（增删改查）**：
- 列表展示全部概念节点（名称/学科/年级/描述/关键词/状态）；
- 新建节点：填名称、学科（下拉字典）、年级、描述、关键词；
- 编辑节点：修改描述/关键词等属性（Neo4j MERGE 更新，不产生重复）；
- 删除节点：连同其关系一并删除（有二次确认）；
- 支持关键词搜索与学科筛选。

### 4.4 题库管理（/teacher/question）

- 题目列表：题型、学科、难度、关联知识点、典型例题；
- 新建/编辑/删除题目；支持按学科、题型、难度筛选；
- 题目可挂接图谱中的概念节点，供学生「在线练习」调用。

### 4.5 文档管理（/teacher/document）

- **纯管理页**：查看历史上传的全部文档（标题/类型/解析状态/上传时间），支持标题搜索；
- 「查看结果」预览文档的解析结果；「删除」清理文档与磁盘文件（已关联知识入库任务的文档会被拒绝删除，保护溯源链）；
- **上传请走「知识入库」**（旧版直接上传入口已移除，统一走 抽取 → 教师确认 → 入库 的正规流程）。

### 4.6 知识入库（/teacher/extract）★核心业务

三 Tab 上传：**教案 / 讲义 / 纯知识点**。

- 教案/讲义：拖拽上传 .docx / .pdf / .md / .txt（≤20MB），建议命名 `学科_年级_课题_作者_日期.docx`；
- 纯知识点：在线粘贴文本，或下载 Excel 模板批量录入（支持填写前置概念）；
- 上传后自动进入流水线：解析 → 大模型抽取（每条带置信度和原文摘录）→ 与 Neo4j 现有节点去重预匹配（精确/模糊两级）；
- 完成后任务进入「确认中心」，状态为**待确认**。

### 4.7 确认中心（/teacher/confirm）★人工把关

教师对抽取结果**逐条裁决**（这是防图谱重复的关键环节）：

- **疑似重复组**（优先展示）：左候选、右已有节点（含相似度），三选一裁决：
  - **合并**：不建新点，候选内容补充进已有节点；
  - **建关系**：候选作为已有概念的前置/相关，只建关系不建点；
  - **新建**：确认是不同概念，允许行内编辑名称/学科/描述；
- **新增节点组**：行内编辑；置信度 <0.6 的条目自动置顶并标橙「重点核对」；
- **思维路径组**：步骤可拖拽排序、增删步、编辑提示语；
- 支持「全部接受建议」快捷键、草稿自动保存（可分多次确认）、手动补漏添加抽取遗漏的知识点；
- 全部裁决完后「提交入库」→ 事务写入 Neo4j（MERGE 幂等，不产生重复节点）→ 任务转**已发布**；
- 每个任务支持：**发布 / 下线 / 回滚**（回滚精确删除本任务新建的节点，种子节点不受影响，ingest_log 留审计链）。

### 4.8 教研看板（/teacher/research）

- 指标卡：节点总数 / 本月新增 / 待确认 / 待解答；
- 图谱增长曲线（近 30 天）、学科覆盖雷达图、来源分布（哪份教案贡献多少节点）；
- **卡点教研**：班级 × 题型 × 时间三维聚合，输出教研建议（如"3 班化学平衡卡点集中，建议回补前置概念"）；
- **缺口清单**：学生高频问但图谱中没有对应概念的问题，自动生成「待补充知识点」清单，可**一键转为知识点上传任务**——学生的问题直接变成下一轮备课输入。

### 4.9 问题解答（/teacher/faq-manage）★高频问题工作台

- 顶部统计卡：**待解答 / 已发布解答 / 聚合问题总数**；
- 问题列表：学生追问自动聚合为高频问题，按热度（ask_count）排序，显示状态标签与解答预览；
- **写解答**：点击行内「写解答」，在对话框撰写标准解答 → 「发布解答」→ 学生提问命中后直接看到官方解答；
- **智能归并相似问题**：一键调用大模型对全部高频问题做语义聚类，把「同一个问题的不同问法」归并为一条（自动保留已发布有解答的作为基准、累加热度、迁移反馈）。⚠️ 归并不可逆，操作前有二次确认；大模型不可用时**不会改动任何数据**，只提示稍后重试。归并耗时约 1–2 分钟（免费档限流所致）属正常现象。

### 4.10 学情分析（/teacher/analysis）

- 按班级/学生查看练习正确率、提问分布、卡点概念排行；
- 时间维度趋势；个体学生的学习路径与薄弱环节。

## 五、学生端功能与操作

登录后默认进入「个人面板」。

### 5.1 个人面板（/student/dashboard）

- 学习数据总览：练习次数、正确率、最近学习记录；
- 我的薄弱知识点（基于答题与追问记录推算）；
- 高频问题与图谱入口卡片。

### 5.2 智能追问（/student/chat）

- 对话框式 AI 答疑，**回答逐字流式输出**（发送后立刻出现「正在思考」气泡，大模型边生成边显示，不再卡顿等整段）；
- **优先检索知识图谱与高频问题库**：
  1. 提问先查 faq 高频问题（相似度匹配）→ 命中先展示教师标准解答，再问"还有哪里不清楚"；
  2. 未命中则结合 Neo4j 图谱中该概念的描述/前置概念做思维路径引导式回答；
  3. 每个学生的提问自动聚合进高频问题库，供教师解答；
- 支持多轮上下文对话；回答中引用的概念可点击查看图谱位置。

### 5.3 高频问题（/student/faq）

- 高频问题榜：问题摘要 + 提问人数 + 状态（已发布解答 / 教师解答中）；
- 展开折叠查看**官方解答**；解答下可点「有用 / 无用」反馈（回流给教师看解答质量）；
- 「我也有这个疑问」→ 一键跳转智能追问并自动带上该问题上下文。

### 5.4 知识图谱（/student/graph）

- 学生版 3D 图谱：滚轮缩放、拖拽、点击节点展开关联；
- 点击节点显示概念描述与**来源信息**（如「📄 盐类水解知识点 · 王老师 提供」，种子节点显示「系统预置知识点」）；
- 与教师端设计不同：学生端更强调探索式浏览与学习路径感，不提供编辑入口（只读）。

### 5.5 在线练习（/student/practice）

- 按学科/知识点选题作答；提交后即时判分与解析；
- 答错题目自动记录卡点，回流到学情分析与教师端教研看板。

### 5.6 学情报告（/student/profile）

- 个人学习报告：各科掌握度雷达、练习历史、提问历史、薄弱概念清单与建议复习路径。

## 六、关键业务闭环速查

| 场景 | 操作路径 |
|---|---|
| 把一份教案变成图谱知识 | 知识入库 → 上传教案 → 确认中心逐条裁决 → 提交入库 → （自动发布） |
| 发现学生总问某个不会的点 | 问题解答 → 找到该高频问题 → 写解答并发布 |
| 发现图谱里缺学生问的概念 | 教研看板 → 缺口清单 → 一键转上传 → 按知识点补录 |
| 某次入库内容有误 | 确认中心/文档管理 → 找到任务 → 回滚（精确撤销该任务新增的节点） |
| 想知道某个知识点哪来的 | 教师/学生端图谱 → 点击节点 → 查看来源教案与教师 |
| 问题列表太碎（同一问题多种问法） | 问题解答 → 智能归并相似问题（等 1–2 分钟刷新） |

## 七、注意事项

1. **账号与安全**：所有接口走 sa-token 鉴权；后端重启后需重新登录。
2. **大模型 Key**：AI 服务使用 kimi-k2.6（reasoning 模型），免费档有并发与速率限制——抽取/归并任务耗时较长属正常；`ai-service/services/llm.py` 中换 Key 即可（`api_key` 与 `base_url`）。
3. **数据导入**：`import-data.bat` 幂等可重复执行；Neo4j 里没数据时页面图谱为空，先跑导入脚本。
4. **不可恢复的操作**：归并相似问题不可逆（有确认弹窗）；节点删除与任务回滚请谨慎。
5. **大模型不可用时的降级**：抽取任务会用关键词规则降级（置信度统一标 0.3，全部进入人工核对）；归并任务直接报错不动数据；智能追问自动跳过 LLM 用图谱规则回答。
