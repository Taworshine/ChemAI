## 一、根目录：启动脚本与数据脚本

| 文件 | 讲解 |
|---|---|
| `README.md` | 项目根说明（系统简介 + 快速启动指引）。 |
| `start-all.bat` | **一键启动**（6 步）：检查/启动 Neo4j（7687，未运行则 neo4j.bat console 并等待 15 秒）→ 调 `init-sql.bat` **先导入 MySQL 数据** → 调 `import-data.bat` **再导入 Neo4j 图谱数据** → 起 AI 服务(8000) → 起 Java 后端(8080) → 起前端(5173)。每步一个独立 cmd 窗口。 |
| `stop-all.bat` | 一键停止：按端口(7687/8000/8080/5173)查找并 kill 对应进程。 |
| `init-sql.bat` | MySQL 一键导入（可反复执行）：3306 未监听则自动 `net start MySQL80`；自动扫描 `sql\*.sql` 按文件名顺序执行（00 整库重置 → 01 建库 → 02 扩展表 → 03/04 种子数据，加新脚本扔文件即可），最后查询 users/questions/profiles/sessions 四表计数校验。参数 `nopause` 时不暂停（供 start-all 调用）。 |
| `import-data.bat` | 数据导入（可反复执行）：自动扫描 `seeds\*.cypher` 按文件名顺序执行（00 清空 → 01 化学 → 02 多学科，加新数据扔文件即可），最后跑 `check_data.cypher` 打印校验结果。参数 `nopause` 时不暂停（供 start-all 调用）。 |
| `cypher.bat` | Neo4j 脚本执行器：`type 脚本 \| cypher-shell -u neo4j -p ppsxngS4`。内部注入了 Java 17 路径并强制 JVM UTF-8（**必须用它执行 cypher，否则中文乱码入库**）。 |
| `seeds/00_reset.cypher` | 一句 `MATCH (n) WHERE n:Concept OR ... DETACH DELETE n`，只清本系统四类节点，不动库里其他项目数据。 |
| `seeds/01_init.cypher` | Neo4j V1 种子：约束（name/id 唯一）+ 化学 8 概念/5 题型/路径/卡点及关系，节点带画布坐标 x/y。 |
| `seeds/02_seed_v2.cypher` | Neo4j V2 多学科扩展：数学/物理/生物/语文/英语/政治/历史/地理的概念、题型、思维路径、卡点。 |
| `check_data.cypher` | 统计查询：按学科数概念、题型/路径/卡点总数、关系总数，导入后自动校验用。 |
| `sql/00_reset.sql` | MySQL 整库重置：`DROP DATABASE IF EXISTS mind_empower`，让整套脚本可以无限次重复执行（幂等的根基）。 |
| `sql/01_schema.sql` | MySQL V1 建库：用户表、题库表等（utf8mb4）。 |
| `sql/02_schema_v2.sql` | MySQL V2 扩展：练习记录表、学生画像表、教案表、AI 会话/消息表等。 |
| `sql/03_seed_mysql.sql` | MySQL V1 种子：教师 teacher/123456、学生 2023001-20230010/123456、初始化学题库。 |
| `sql/04_seed_v2_mysql.sql` | MySQL V2 种子：多学科题库等扩展数据。 |

## 二、后端 `backend/`（Maven 多模块，单 jar 运行）

### 工程骨架
| 文件 | 讲解 |
|---|---|
| `pom.xml` | 父 POM：声明 6 个子模块、Spring Boot 3.2.12 依赖管理（web/validation/mysql/mybatis-plus/neo4j-java-driver/sa-token）。 |
| `mind-server/pom.xml` | 启动模块 POM：聚合其余模块打成可执行 jar（`mind-server-1.0.0.jar`）。 |
| `mind-server/.../MindServerApplication.java` | Spring Boot 主类，整个后端的入口。 |
| `mind-server/.../config/SaTokenConfig.java` | sa-token 拦截器：拦截 `/api/**`，仅放行 `/api/auth/login`——这就是"没带 token 访问全部 500"的原因。 |
| `mind-server/.../resources/application.yml` | 配置：8080 端口、MySQL 数据源(HikariCP)、Neo4j bolt://localhost:7687、AI 服务地址 http://localhost:8000。 |

### mind-common —— 公共层
| 文件 | 讲解 |
|---|---|
| `pom.xml` | 公共模块 POM。 |
| `common/Result.java` | 统一响应体 `{code, msg, data}`，前端拦截器按 `code===200` 判定成功。 |
| `common/ai/AiServiceClient.java` | AI 服务客户端：向 Python 服务(8000)发 HTTP 请求（聊天追问、文档解析），带超时与降级。 |

### mind-system —— 系统/认证层（`/api/auth`）
| 文件 | 讲解 |
|---|---|
| `controller/AuthController.java` | `POST /api/auth/login`（校验 MySQL 用户表 → sa-token 发令牌）、`POST /logout`、`GET /info`（当前登录人）。 |
| `entity/SysUser.java` | 用户实体（账号、密码、角色 teacher/student、姓名）。 |
| `mapper/UserMapper.java` | MyBatis-Plus Mapper，操作用户表。 |

### mind-knowledge —— 知识层（图谱/题库/教案，`/api/graph`、`/api/question`、`/api/document`）
| 文件 | 讲解 |
|---|---|
| `controller/GraphController.java` | 图谱只读接口：`GET /full`（全量节点+关系，前端图谱页的数据源）、`GET /subjects`（学科列表）、`GET /nodes`（节点搜索）。Cypher 查询 Neo4j 后统一转成 `{id, label, props}` 结构。 |
| `controller/GraphAdminController.java` | 图谱管理接口：`POST /node`（新增节点）、`POST /edge`（创建关系）、节点更新与删除（`DETACH DELETE`）——后台增删改查的落点。 |
| `controller/QuestionBankController.java` | 题库 CRUD：按学科/难度分页查询、新增、修改、删除（MySQL）。 |
| `controller/DocumentController.java` | 教案接口：`POST /upload`（接收 PDF/Word 存盘并登记 MySQL）、`POST /parse/{id}`（调 AI 服务解析提取知识点）。 |
| `entity/QuestionBank.java` / `entity/EduDocument.java` | 题库 / 教案实体。 |
| `mapper/QuestionBankMapper.java` / `mapper/DocumentMapper.java` | 对应 MyBatis-Plus Mapper。 |

### mind-analysis —— 学情层（`/api/analysis`、`/api/practice`）
| 文件 | 讲解 |
|---|---|
| `controller/AnalysisController.java` | `GET /class/heatmap`（班级答题热力图）、`GET /student/{id}/radar`（能力雷达图）、`GET /students`、`GET /history/{id}`、`GET /stats` 等。 |
| `controller/PracticeController.java` | 在线练习：`GET /questions`（抽题）、`POST /submit`（判分入库）、`GET /records`（历史记录）。 |
| `entity/PracticeRecord.java` / `entity/StudentProfile.java` | 练习记录 / 学生画像实体。 |
| `mapper/PracticeRecordMapper.java` / `mapper/StudentProfileMapper.java` | 对应 Mapper。 |

### mind-agent —— AI 对话层（`/api/agent`）
| 文件 | 讲解 |
|---|---|
| `controller/AgentController.java` | `POST /session`（开新会话）、`POST /chat`（SSE 流式转发 AI 服务追问回答）、`GET /sessions`、`GET /history/{id}`。 |
| `entity/DialogSession.java` / `entity/DialogMessage.java` | AI 会话 / 消息实体（MySQL 持久化聊天记录）。 |
| `mapper/DialogSessionMapper.java` / `mapper/DialogMessageMapper.java` | 对应 Mapper。 |

> 说明：`*_run.log`、`*_java.log`、`*_live.log` 是历次启动的日志留档，可随时删除。

## 三、AI 服务 `ai-service/`（FastAPI，端口 8000）

| 文件 | 讲解 |
|---|---|
| `requirements.txt` | 依赖：fastapi、uvicorn、openai（DeepSeek 兼容接口）、pdfplumber、python-docx、python-multipart。 |
| `main.py` | 服务入口：创建 FastAPI 应用、挂载 extract/chat 两个路由、`/api/health` 健康检查（含 LLM 是否可用）、uvicorn 启动。 |
| `routers/extract.py` | 教案解析接口：接收文件流，调 parser 抽取文本 → 提知识点 → 返回结构化结果给后端。 |
| `routers/chat.py` | 追问对话接口：接收学生问题+学科+历史，调 llm 生成苏格拉底式追问，SSE 流式返回。 |
| `services/llm.py` | LLM 核心：读环境变量 `DEEPSEEK_API_KEY/BASE_URL/MODEL`（默认 api.deepseek.com / deepseek-chat）；**未配置 Key 时自动降级为内置规则引导引擎**（按学科关键词匹配启发式追问模板，所以系统离线也能演示）。 |
| `services/parser.py` | 文档解析：pdfplumber 抽 PDF 文本、python-docx 抽 Word 文本，再按学科词表切分知识点。 |

## 四、前端 `frontend/`（Vue 3 + Vite，端口 5173）

| 文件 | 讲解 |
|---|---|
| `package.json` | 依赖清单：vue3、vue-router4、element-plus、@element-plus/icons-vue、axios、echarts、@antv/g6；devDependencies：vite5、@vitejs/plugin-vue。 |
| `vite.config.js` | Vite 配置：vue 插件 + **dev proxy**：`/api` → `http://localhost:8080`（前端不用关心跨域）。 |
| `index.html` | 单页入口 HTML。 |
| `src/main.js` | 前端入口：挂载 App、注册路由、引入 Element Plus 与全局样式。 |
| `src/App.vue` | 根组件（仅 `<router-view/>`）。 |
| `src/router/index.js` | 路由表 + 守卫：`/login` 公开，其余按 `localStorage` 中的角色（teacher/student）分流到教师端/学生端，未登录跳回 `/login`。 |
| `src/api/index.js` | axios 实例：baseURL `/api`；请求拦截器自动带 `satoken` 头；响应拦截器统一判 `code===200`、401 时清登录态跳回登录页、错误弹 ElMessage。 |
| `src/utils/graphRender.js` | **图谱渲染核心（两端共用）**：颜色/中文名映射；`toG6Data` 把后端数据转成 G6 数据——节点全部圆形 + 径向渐变 3D 球体（左上受光）+ 深色描边 + 投影，边为曲线箭头；`filterBySubject/filterByKeyword` 学科/关键词过滤；`createGraph` 创建 G6 实例：拖拽/缩放/悬停提示，自定义悬停"上浮放大+加深阴影"，**聚焦模式**（点击节点淡出无关节点，点空白还原），并对外暴露 click/dragend 钩子。 |
| `src/views/Layout.vue` | 双端共用的页面框架：顶栏（系统名+用户信息+退出）+ 侧边菜单（按角色渲染不同菜单项）。 |
| `src/views/Login.vue` | 登录页：账号密码 → `POST /auth/login` → 存 token 和角色 → 按角色跳转。 |

## 五、阅读顺序建议

1. `docs/01` 了解系统能做什么、怎么启动；
2. `docs/02` 了解技术选型和进程关系；
3. 想改某个功能时，按 `docs/03` 找到对应文件，从 Controller / 路由文件入手，再顺着 Service / Mapper / 组件往下读。
