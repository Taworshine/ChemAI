# 思维赋能 · 教研会议 APP 改版设计方案 v3

> 本版重点解决两件事：**页面太乱**（做减法、每屏一个核心任务）、**命名不直观**（全套说人话的界面文案）。
> 请在文中直接改，确认后实施。技术架构与数据库改动沿用 v2 第 7、8 节不变。

---

## 1. 设计原则（先立规矩）

1. **每屏只做一件事**：一屏最多一个主按钮，其余操作收进次级入口或"⋯"。
2. **三段式页面**：每个页面只有 顶部（这是什么）→ 中部（内容）→ 底部（我要做什么）三个区域，不叠层。
3. **命名三条铁律**：
   - 用**动词开头**说动作：发起会议、加入会议、上传教案、发起投票
   - 不用术语：~~议程~~→会议类型、~~量化评审~~→教案体检、~~批注~~→圈画点评
   - 同一东西全 APP 只叫一个名字（见第 5 节命名表）
4. **状态一眼可见**：进行中=绿点呼吸，待开始=灰色圆点，已结束=灰字"已结束"，不使用彩色药丸堆在标题旁。

## 2. 页面清单（全 APP 只有 6 个页面）

| # | 页面 | 名称 | 作用 |
|---|---|---|---|
| 1 | 首页 | 会议 | 看会、进会、发起会 |
| 2 | 会议中 | 会议现场 | 一个页面开完整个会 |
| 3 | 学情 | 学情 | 看班级掌握情况 |
| 4 | 我的 | 我的 | 个人相关的一切 |
| 5 | 会议纪要 | 纪要详情 | 会后自动生成的纪要 |
| 6 | 加入会议 | 加入会议 | 输 6 位码进会（也支持扫码直达） |

> 砍掉的页面：创建会议页（并入首页弹层）、量化评审页（并进会议现场）、加入页签式列表。

## 3. 页面设计（线框图）

### 3.1 首页 = 「会议」

```
┌──────────────────────────────┐
│  教研会议              ⚙ 扫一扫 │  ← 顶栏：标题+两个图标（扫一扫/设置）
├──────────────────────────────┤
│                              │
│   ┌──────────────────────┐   │
│   │   ＋  发起会议        │   │  ← 全宽主按钮，全屏唯一主色块
│   └──────────────────────┘   │
│                              │
│  ── 进行中 ──────────────    │  ← 分组标题，灰色小字
│  ┌────────────────────────┐  │
│  │ ● 氧化还原教案评审      │  │  ← 会议卡：状态点+标题
│  │ 今天 14:00 · 王老师主持 │  │
│  │ 3 条新讨论      进入 ›  │  │  ← 底部一行：动态提示+进入
│  └────────────────────────┘  │
│                              │
│  ── 待开始 ──────────────    │
│  ┌────────────────────────┐  │
│  │ ○ 集体备课：函数单调性  │  │
│  │ 明天 09:00 · 李老师主持 │  │
│  └────────────────────────┘  │
│                              │
│  ── 待办(2) ─────────────    │  ← 未完成数放标题里，不用红点到处飞
│  ┌────────────────────────┐  │
│  │ ◻ 修改第 3 页导入环节   │  │
│  │ 氧化还原评审会 · 截止明天 │  │
│  └────────────────────────┘  │
│                              │
│  ── 已完成 ──────────────    │  ← 默认折叠，点开展开
└──────────────────────────────┘
```

**规则**：
- 不再分"我主持的/我参与的/历史"三个页签——按**会议状态**分组，人关心的首先是"哪个会正在进行"。
- 会议卡**整卡可点**，点哪都进会议现场；"进入 ›"只是视觉提示不是单独按钮。
- 点右上角 ⚙ 进"我的"页；扫一扫调相机扫码直接进会。

### 3.2 会议中 = 「会议现场」（单页整合）

```
┌──────────────────────────────┐
│ ‹  氧化还原教案评审      ● 进行中 │  ← 顶栏：返回+标题(过长滚动)+状态
├──────────────────────────────┤
│ 讨论(3) 教案 圈画 投票 成员    │  ← 页签栏，默认在"讨论"
├──────────────────────────────┤
│                              │
│         （页签内容区）         │  ← 五个页签共用这一片区域
│                              │
├──────────────────────────────┤
│  说点什么…              发送   │  ← 讨论页签时的底部输入条
└──────────────────────────────┘
```

页签内容（每个页签也只保留一个核心操作）：
- **讨论**：消息流 + 底部输入条（现状保留，样式不变）
- **教案**：教案图占满 + 右下角悬浮"✎ 圈画"一个按钮；点开圈画才出笔色条（收起时不占屏幕）
- **圈画**：批注列表，每条卡片只有 头像+名字+内容+一行操作（回复 / 已解决）
- **投票**：列表卡片，主持人卡片顶部有"＋ 发起投票"，其他人看不到这个入口
- **成员**：一行人一个，头像+名字+（主持人）角标，主持人可对他人点"⋯"移出

**砍掉的元素**：锁定按钮移进"⋯"；会议号只在顶栏标题下小字显示一次，长按复制；结束会议收进主持人"⋯"菜单。

## 4. 交互流程（只保留 3 条主干）

1. **发起**：首页"发起会议" → 弹层三步（主题+学科 → 会议类型 → 选人）→ 直接进会议现场
2. **加入**：首页扫一扫 / 输码 → 直达会议现场
3. **会后**：主持人"⋯"→ 结束会议 → 弹窗"生成会议纪要？" → 生成 → 全员"我的-会议纪要"可见

## 5. 命名规范全表（统一口径）

| 不叫（旧/术语） | 统一叫（新） | 说明 |
|---|---|---|
| 创建会议 | 发起会议 | 动词开头 |
| 输码加入 | 加入会议 | "输码"是方式不是动作 |
| 我主持的/我参与的/历史 | 进行中 / 待开始 / 已完成 | 按用户关心度分组 |
| 议程 | 会议类型 | 老师听得懂 |
| 批注（页签） | 圈画 | 页签只放手绘批注，文字点评并入讨论 |
| 快速文字批注 | （取消，并入讨论） | 减少一个概念 |
| 量化评审 | 教案体检 | 一键体检更直观 |
| AI 解析 | 智能解析 | |
| 手绘批注已同步 | 圈画已同步给所有人 | |
| 锁定/解锁会议 | 暂停加入 / 恢复加入 | |
| 移出 | 请出会议 | 柔和 |
| 待办 | 会后任务 | 和会议纪要里的叫法一致 |
| 服务器地址 | 服务器连接（状态：已连接/未连接） | 显示结果而不是配置项 |
| 运行模式（H5 调试…） | （删除，用户不需要知道） | |
