# 完整技术栈

## 一、总体架构（4 个进程）

```
浏览器 (Vue 3 前端 :5173)
   │  /api → vite dev proxy → Java 后端 (:8080)
   │                              ├── MySQL 8.0   （用户/题库/练习/教案，JDBC）
   │                              ├── Neo4j 5.26  （知识图谱，Bolt 7687，官方 Java Driver）
   │                              └── Python AI 服务 (:8000, HTTP 调用)
Neo4j Browser (:7474, 仅人工查看)
```

## 二、后端（Java）

| 项 | 选型 |
|---|---|
| 语言 / 运行时 | Java 17（本机 `E:\Java\Java 17`） |
| 框架 | Spring Boot 3.2.12（Web + Validation） |
| 构建 | Maven 3.9.11，多模块工程（6 个 module） |
| 认证 | **sa-token 1.39**（登录态、路由拦截 `/api/**`，仅放行 `/api/auth/login`） |
| 关系库 | MySQL 8.0 + MyBatis-Plus（HikariCP 连接池） |
| 图库 | Neo4j Community 5.26.9 + 官方 Neo4j Java Driver（直接跑 Cypher） |
| HTTP 客户端 | Spring RestClient / RestTemplate（调用 AI 服务） |
| 打包 | 单 jar：`mind-server-1.0.0.jar`，`java -jar` 启动 |

## 三、AI 服务（Python）

| 项 | 选型 |
|---|---|
| 框架 | FastAPI + Uvicorn（端口 8000） |
| LLM | DeepSeek（OpenAI 兼容 SDK；未配置 `DEEPSEEK_API_KEY` 时自动降级为内置规则引导引擎） |
| 文档解析 | pdfplumber（PDF）、python-docx（Word） |
| 核心能力 | 教案知识点抽取（`/extract`）、多学科苏格拉底式追问（`/chat`，SSE 流式输出） |

## 四、前端

| 项 | 选型 |
|---|---|
| 框架 | Vue 3.5（`<script setup>` 组合式 API） |
| 构建 | Vite 5.4 + @vitejs/plugin-vue |
| UI 组件 | Element Plus 2.9 + @element-plus/icons-vue |
| 图谱可视化 | **AntV G6 4.8**（力导/自定义坐标布局、径向渐变节点、状态系统 hover/selected/faded） |

## 五、数据库

| 库 | 内容 |
|---|---|
| Neo4j（库名 `neo4j`） | 节点标签：`Concept`（概念）、`QuestionType`（题型）、`ThinkingPath`（思维路径）、`Misconception`（卡点）；关系：`PREREQUISITE` 前置知识、`HAS_QUESTION_TYPE` 包含题型、`REQUIRES_PATH` 思维路径、`COMMON_MISCONCEPTION` 常见卡点 |

## 七、已知约定与坑

1. 执行 `.cypher` 脚本必须走 `cypher.bat`（靠 `JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8` 保证 JVM 以 UTF-8 解码 stdin）；直接调 cypher-shell 会用系统默认 GBK 解码，把中文乱码入库。
2. 所有 `.bat` 文件必须 **GBK 编码 + CRLF 行尾**。不要用 UTF-8 + `chcp 65001` 的组合——cmd 解析变长多字节字符时会把一行切碎、半截汉字被执行成"不是内部或外部命令"。
3. `import-data.bat` 的校验段前后用 `chcp 65001` / `chcp 936` 包裹：因为 JVM 输出是 UTF-8，临时切 65001 才能正确显示学科名，看完立即切回 936 不影响后续 GBK 文本。
4. 前端接口统一走 `/api` 前缀，由 vite proxy 转发到 8080。
5. 后端除 `/api/auth/login` 外全部需要 `satoken` 请求头。
6. `init-sql.bat` 与 `import-data.bat` 均为**重置式导入**（00 号脚本永远先执行）：每次 `start-all.bat` 启动都会把 MySQL / Neo4j 恢复为种子状态，练习记录、聊天记录等使用数据会被清空——这是"先导入数据再进页面"和幂等性两个需求共同决定的语义，使用时需知情。
7. `.bat` 里给 `mysql -e "..."` 命令追加 `2>nul` 时只能加在**闭引号之后**：`mysql ... -e "SQL" 2>nul`。若写进引号里会被当成 SQL 的一部分，MySQL 报 `ERROR 1064 near '2>nul'`。
