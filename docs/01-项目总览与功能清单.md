# 思维赋能 · 高中教学辅助系统 — 项目总览

> 一套面向高中全学科（语数英物化生政史地）的教学辅助系统，
> 核心特色是 **Neo4j 知识图谱** + **AI 苏格拉底式追问** + **教师/学生双端分离**。

## 一、系统功能总览

### 教师端
| 功能 | 说明 |
|---|---|
| 工作台 Dashboard | 学科/节点统计、图谱概览、待办入口 |
| 知识图谱管理 Graph | 可视化图谱（3D 球体节点、聚焦模式）、节点增删改查、创建关系连线、按学科筛选、关键词搜索 |
| 知识管理 Knowledge | 知识点列表的集中维护 |
| 题库管理 QuestionBank | 题目的增删改查、按学科/难度筛选 |
| 教案/文档管理 Document | 上传教案（PDF/Word），AI 自动解析提取知识点 |
| 学情分析 Analysis | 班级热力图、单个学生能力雷达图、练习历史 |

### 学生端
| 功能 | 说明 |
|---|---|
| 知识图谱浏览 GraphView | 与教师端同款的 3D 图谱可视化（只读 + 详情面板 + 相关知识点跳转） |
| AI 智能问答 Chat | 苏格拉底式追问：AI 不直接给答案，而是按学科规则逐步启发引导 |
| 在线练习 Practice | 从题库抽题作答、提交判分 |
| 个人中心 Profile | 练习记录、能力画像 |

### 管理后台能力
- 所有图谱节点（概念/题型/思维路径/卡点）和关系支持完整 **增删改查**，直接落 Neo4j。
- 题库、教案、学生账号均通过 MySQL 持久化，支持维护。

## 二、数据规模（种子数据）

- **Neo4j 图谱**：20 个概念（化学 8、数学 3、物理 2、生物 2，政史地语英各 1）、18 个题型、28 条思维路径、17 个常见卡点、199 条关系。
- **MySQL**：用户表（教师 1 + 学生 10）、题库、练习记录、教案元数据等（`sql/03_seed_mysql.sql` / `sql/04_seed_v2_mysql.sql`）。

## 三、启动方式

| 场景 | 操作 |
|---|---|
| 一键启动（推荐） | 双击 `start-all.bat`：检查/启动 Neo4j → **导入 MySQL 数据**（init-sql.bat）→ **导入 Neo4j 图谱数据**（import-data.bat）→ AI 服务(8000) → Java 后端(8080) → 前端(5173) |
| 只导数据 | MySQL 双击 `init-sql.bat`（整库重置→按顺序执行 sql\ 全部脚本→校验，可反复执行）；Neo4j 双击 `import-data.bat`（清空→导入→校验，可反复执行） |
| 全部停止 | 双击 `stop-all.bat` |

访问入口：http://localhost:5173

演示账号：教师 `teacher / 123456`；学生 `2023001` ~ `20230010` / `123456`

Neo4j Browser：http://localhost:7474/browser/ （账号 `neo4j / ppsxngS4`，**左上角数据库选 `neo4j`**）
