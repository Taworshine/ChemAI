# 06 · 前端：骨架（入口 / 路由 / 请求 / 布局 / 登录）

## 1. vite.config.js（15 行）—— dev 服务器与代理

```js
server: {
  port: 5173,
  proxy: { '/api': { target: 'http://localhost:8080', changeOrigin: true } }
}
```
开发时浏览器只访问 5173，`/api` 开头的请求由 Vite 转发到 Java 后端——**前端代码里没有任何一处写死 8080**，生产构建后则由部署层的反向代理接管。

## 2. main.js（12 行）—— 应用引导

`createApp(App)` → 注册 Element Plus（**中文语言包 zhCn**，日期/分页等组件显示中文）→ 注册 vue-router → 挂载 `#app`，并引入全局样式 `styles/main.css`（定义 `--primary`、`--ink` 等 CSS 变量和 `.soft-card` 通用卡片类，全站"柔和高端"风格的基底）。

## 3. App.vue（3 行）—— 根组件

只有一个 `<router-view/>`，本身无逻辑。

## 4. router/index.js（36 行）—— 路由表 + 权限守卫

- 路由结构：`/login` 公开；`/` 下挂 Layout，10 个子路由分 teacher/* 和 student/* 两组，`meta.role` 标注所需角色，`meta.title` 给顶栏面包屑用。全部用 `() => import(...)` 动态导入（路由级代码分割）。
- 全局前置守卫 `beforeEach` 做三道判断：
  1. `meta.public` 直接放行；
  2. localStorage 无 `satoken` → 跳 `/login`；
  3. 路由要求角色与当前角色不符 → 强制送回自己角色的首页。
- 根路径 `/` 的 `redirect` 按角色分流教师工作台 / 学生追问页。

## 5. api/index.js（33 行）—— axios 实例 + 两个拦截器

```js
const api = axios.create({ baseURL: '/api', timeout: 70000 })
```
70 秒超时是为了覆盖后端 60 秒 AI 读超时（教案解析）。

- **请求拦截器**：从 localStorage 取 `satoken` 放进 `config.headers.satoken` ——与后端 `sa-token.token-name` 配置严丝合缝。
- **响应拦截器**：
  - 业务判断：响应体含 `code` 字段时，`200` 直接返回 `body`（所以页面里写 `res.data.xxx` 而不是 `res.data.data.xxx`）；非 200 弹 ElMessage 错误并 reject；
  - HTTP 层错误：401 时清 localStorage 并跳登录页；其余弹错误提示。

**SSE 例外**：Chat.vue 的流式接口不能用 axios（它把响应当成一次性 JSON），所以那里用原生 `fetch` + 手动拼 `satoken` 头。

## 6. Layout.vue（156 行）—— 双端共用框架

模板三段：
- **侧边栏**：logo 区（烧瓶 SVG + "思维赋能"）+ `el-menu`。菜单项用 `v-if="role === 'TEACHER'"` 分流——教师 6 项（工作台/知识图谱/知识管理/题库管理/文档管理/学情分析），学生 4 项（智能追问/知识图谱/在线练习/学情报告）。`:default-active="$route.path"` 让菜单高亮跟随路由。
- **底栏用户卡**：头像取 realName 首字，点退出图标调 `POST /auth/logout` → 清 localStorage → 跳登录页。
- **顶栏**：左侧显示当前页 `meta.title`，右侧显示当天日期（`toLocaleDateString('zh-CN', {...weekday:'long'})`）。
- 挂载时调 `GET /auth/info` 刷新真实姓名写回 localStorage——**任何页面刷新后名字都正确**。

样式要点：菜单项圆角 + 激活项渐变浅蓝底、顶栏半透明毛玻璃（`backdrop-filter: blur`）、logo 图标蓝紫渐变投影——这套视觉在全局 main.css 和各页面 scoped 样式中保持一致。

## 7. Login.vue（134 行）—— 登录页

- 左 55% 品牌区：蓝紫渐变底 + 装饰圆 + 纯内联 SVG 插画（烧瓶/烧杯/分子连线），右 45% 玻璃拟态登录卡（`backdrop-filter: blur`）。
- 登录逻辑 `doLogin`：非空校验 → `POST /auth/login` → 把 `token / role / realName / userId` 四项写入 localStorage → 按角色 `router.push` 到对应首页。
- 底部直接展示演示账号（teacher / 123456 与 2023001~2023010），方便验收演示。
- 视觉细节：登录按钮 8 字间距、`letter-spacing`、渐变蓝底+投影，回车键 `@keyup.enter` 直接提交。
