# 10 · 脚本与数据文件

## 一、批处理脚本（Windows，**必须 GBK 编码 + CRLF 行尾**）

> 历史教训：曾用 UTF-8 + `chcp 65001` 写 bat，cmd 解析变长多字节字符时把整行切碎，
> 半截汉字被执行成 `'��识别' is not recognized` 之类的报错。改成 GBK（中文 Windows 原生代码页）后彻底解决。

### start-all.bat —— 一键启动（6 步流水线：先导数据，再启服务）
```bat
set "JAVA_HOME=E:\Java\Java 17"          :: Java 不在系统 PATH，脚本内自己注入
netstat -ano | findstr ":7687 " | findstr "LISTENING"
```
1. **查 Neo4j**：`netstat | findstr :7687 + LISTENING` 判断是否在跑；没在跑就 `start "Neo4j" /min neo4j.bat console`（独立最小化窗口）并 `timeout /t 15` 等待初始化；
2. **导 MySQL**：`call init-sql.bat nopause`——MySQL 侧数据导入（整库重置→按顺序执行 sql\ 全部脚本→校验）；
3. **导 Neo4j**：`call import-data.bat nopause`——"先导入 Neo4j 再进页面"步骤；
4~6. 分别 `start` 三个独立 cmd 窗口跑 AI 服务（uvicorn）、Java 后端（java -jar）、前端（npm run dev）。
每个 `start "标题" cmd /k "..."` 的 `/k` 让窗口留在桌面上——**关闭对应窗口即停止对应服务**。

> 注意：因为 2、3 步是"重置式导入"，每次启动系统数据都会恢复为种子状态（练习记录、聊天记录会被清空）。这正是"先导入数据再进页面"需求与幂等性的折中。

### stop-all.bat —— 一键停止
`for %%P in (5173 8080 8000 7687)` 循环四个端口：`netstat | findstr ":端口 + LISTENING"` 取第 5 列（PID）→ `taskkill /PID /F`。输出每个端口的处理结果，5 秒后自动关窗。

### init-sql.bat —— MySQL 一键导入（幂等，**扫描 sql 文件夹，不写死文件名**）
```
sql\00_reset.sql      整库重置（DROP DATABASE mind_empower）
sql\01_schema.sql     V1 建库建表
sql\02_schema_v2.sql  V2 扩展五张业务表
sql\03_seed_mysql.sql / 04_seed_v2_mysql.sql  种子数据
```
- 开头先探 3306：没监听就 `net start MySQL80`（需管理员权限的服务本来就已安装，普通启动即可）；
- 然后 `for %%F in ("%~dp0sql\*.sql")` 自动遍历，**按文件名字母顺序**逐个喂给 `mysql.exe < 文件`（带 `--default-character-set=utf8mb4` 防中文乱码），逐步显示进度；
- 末尾跑一条 `SELECT` 统计 sys_user / question_bank / student_profile / dialog_session 四表行数做校验（预期 11 / 16 / 10 / 4）；
- 带 `nopause` 参数时不暂停（供 start-all 调用）。
**想加新 MySQL 数据不用改脚本**：往 sql 里放一个 `05_xxx.sql`（数字前缀控制顺序）即可；
因为 00_reset 永远第一个执行，反复运行也不会产生重复数据。

### import-data.bat —— Neo4j 数据导入（幂等，**扫描 seeds 文件夹，不写死文件名**）
```
seeds\00_reset.cypher    清空本系统旧的图谱数据
seeds\01_init.cypher     化学基础图谱
seeds\02_seed_v2.cypher  多学科扩展图谱
```
脚本自动遍历 `seeds\*.cypher`，**按文件名字母顺序**依次执行并逐个显示进度。
**想加新数据不用改脚本**：往 seeds 里放一个 `03_xxx.cypher`（数字前缀控制顺序）即可；
文件夹不存在时自动创建并提示。末尾固定跑 `check_data.cypher` 打印校验统计
（校验段前后有 `chcp 65001` / `chcp 936` 包裹——JVM 输出是 UTF-8，切一下才能正确显示学科名）。
带 `nopause` 参数时不暂停（供 start-all 调用）。因为 00_reset 永远第一个执行，反复运行也不会产生重复数据。

### cypher.bat —— 执行 Cypher 的唯一正确姿势
```bat
set "PATH=E:\Java\Java 17\bin;%PATH%"   :: cypher-shell 需要 Java
set "JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8"
type "%~1" | cypher-shell.bat -u neo4j -p ppsxngS4 --format plain
```
**坑**：直接调 cypher-shell 时 JVM 用系统默认 GBK 解码 stdin，UTF-8 的中文脚本会乱码入库（已经踩过一次，seed 数据全是问号）。这里的关键是 `JAVA_TOOL_OPTIONS` 强制 JVM 按 UTF-8 读管道数据；`type` 输出的是文件原始字节，与控制台代码页无关。

## 二、Cypher 数据脚本（在 Neo4j `neo4j` 库执行，全部位于 `seeds/` 文件夹）

### seeds/01_init.cypher —— V1 化学图谱
- `CREATE CONSTRAINT ... IF NOT EXISTS`：概念名唯一、题型/路径/卡点 id 唯一（幂等，重复执行不报错）；
- 8 个化学 Concept 节点（带 `x/y` 画布坐标、`subject/grade/keywords/description`）、PREREQUISITE 前置关系、5 个题型 + HAS_QUESTION_TYPE、思维路径（stepOrder + hint）+ REQUIRES_PATH、卡点 + COMMON_MISCONCEPTION。

### seeds/02_seed_v2.cypher —— V2 多学科扩展
同样结构，覆盖数学/物理/生物/语文/英语/政治/历史/地理（如政治：市场经济 → 市场调节弊端辨析 → 思维路径/卡点）。用 `CREATE` 而非 `MERGE`，所以**必须配合 reset 使用**（import-data.bat 已保证）。

### seeds/00_reset.cypher —— 定向清空
```cypher
MATCH (n) WHERE n:Concept OR n:QuestionType OR n:ThinkingPath OR n:Misconception DETACH DELETE n;
```
只删本系统四类标签——库里其他项目（旧实验的 Entity/Section 等）不受影响。

### check_data.cypher —— 导入校验
按学科统计概念数 + 题型/路径/卡点/关系总数，import-data.bat 最后打印。

## 三、MySQL 脚本（全部位于 `sql/` 文件夹，init-sql.bat 自动按文件名顺序执行）

### sql/00_reset.sql —— 整库重置
```sql
DROP DATABASE IF EXISTS mind_empower;
```
让整套脚本可以无限次重复执行（幂等的根基），语义与 Neo4j 侧的 seeds/00_reset.cypher 一致。

### sql/01_schema.sql（V1）—— 建 `mind_empower` 库
`CREATE DATABASE ... utf8mb4` + 两张表：`sys_user`（含 role/class_name）、`question_bank`（学科/知识点/题型/题干/答案/难度）。

### sql/02_schema_v2.sql（V2）—— 业务扩展五张表
`practice_record`（学生/学科/得分/总分/detail JSON）、`student_profile`（concept_mastery / thinking_rader 两个 JSON 列）、`edu_document`（文件路径/解析状态/结果 JSON）、`dialog_session` + `dialog_message`（AI 会话与消息，消息带卡点类型和思维步号）。

### sql/03_seed_mysql.sql / sql/04_seed_v2_mysql.sql —— 种子数据
- 用户：教师 `teacher`（密码列存的是 `sha256("123456")` 的十六进制，与 AuthController 的比对逻辑对应）、学生 2023001~2023010，角色 STUDENT；
- V2 补充多学科题库。

执行方式：日常直接用 `init-sql.bat` 一键导入；手动单跑某个脚本的命令：
```bat
"D:\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -ppsxngS4 --default-character-set=utf8mb4 < sql\01_schema.sql
```
（`--default-character-set=utf8mb4` 与 cypher.bat 同理，防中文乱码。）
