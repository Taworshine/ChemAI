# 01 · 后端：启动与公共层

## 1. MindServerApplication.java（18 行）—— 整个后端的入口

```java
@SpringBootApplication(scanBasePackages = "com.mind")
@MapperScan("com.mind.**.mapper")
public class MindServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(MindServerApplication.class, args);
    }
}
```

- `scanBasePackages = "com.mind"`：把分散在 mind-system / mind-knowledge / mind-agent / mind-analysis 四个模块里、包名都是 `com.mind.*.controller` 的类全部扫描进同一个 Spring 容器——**多模块工程能在单 jar 里跑起来的关键**。
- `@MapperScan("com.mind.**.mapper")`：告诉 MyBatis-Plus 去所有模块的 `mapper` 包下找接口并生成代理 Bean，所以各模块的 Mapper 接口不用单独加 `@Mapper` 注解。
- Spring Boot 发现 classpath 里有 `spring-boot-starter-data-neo4j`，就自动配置好一个全局的 `org.neo4j.driver.Driver` Bean，各 Controller 直接构造器注入就能用。

## 3. SaTokenConfig.java（21 行）—— 登录拦截的唯一规则

```java
registry.addInterceptor(new SaInterceptor(handle -> StpUtil.checkLogin()))
        .addPathPatterns("/api/**")
        .excludePathPatterns("/api/auth/login");
```

- `SaInterceptor` 对每个进入 `/api/**` 的请求先执行 `StpUtil.checkLogin()`：从请求头 `satoken` 读令牌，无效就直接抛 `NotLoginException`——**这就是没带 token 访问任何接口都返回 500 的原因**（异常未被全局包装，Spring 直接吐 500）。
- 只放行 `/api/auth/login`。注意它**不区分教师/学生角色**，角色分流是在前端路由守卫做的。

## 4. Result.java（62 行）—— 前后端约定的统一响应体

三个字段：`code`（200 成功 / 401 未登录 / 500 业务错误）、`msg`、`data`。
提供四个静态工厂：`ok(data)`、`ok()`、`error(msg)`、`error(code, msg)`。
所有 Controller 都返回 `Result<T>`，前端 `api/index.js` 的响应拦截器靠 `body.code === 200` 判断成败。

## 5. AiServiceClient.java（87 行）—— Java 调 Python AI 服务的唯一出口

```java
public AiServiceClient(@Value("${ai.service.url:http://localhost:8000}") String baseUrl) {
    SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
    factory.setConnectTimeout(5000);    // 连不上 5 秒就抛异常
    factory.setReadTimeout(60000);      // LLM 生成慢，读超时放宽到 60 秒
    this.restTemplate = new RestTemplate(factory);
}
```

三个对外方法：
- `extract(docId, filePath, text)` → `POST /api/extract`：教案解析。
- `chat(message, history, context)` → `POST /api/chat`：苏格拉底追问。
- `health()` → `GET /api/health`：探活，响应体包含 `"ok":true` 即认为 AI 服务在线。

私有方法 `postForMap`：发 JSON → 拿响应体字符串 → Jackson 解析；**如果返回 JSON 里有 `"ok": false` 就主动抛异常**，让上层（DocumentController / AgentController）走各自的降级逻辑。超时或解析失败同样抛 `RuntimeException`——AI 服务挂了不会让 Java 后端挂，只会让对应接口报错。
