# 08 · 前端：教师端页面

## 1. Dashboard.vue（140 行）—— 工作台

- **5 张统计卡**：在校学生 / 图谱知识点 / 教学文档 / 题库题目 / 练习次数。`onMounted` 里 `Promise.all` 并发打 5 个接口（`/analysis/students`、`/graph/full`、`/document/list`、`/question/list`、`/practice/stats`），用返回数组长度拼出统计值——**没有单独的计数接口，全部复用现有接口**。
- **学科均分柱状图**：ECharts 纵向渐变柱（`LinearGradient(0,0,0,1)` 蓝→浅蓝）、圆角顶部、数值标签，数据来自 `/practice/stats` 的 bySubject。
- **快捷入口**：4 个卡片 `router.push` 到图谱/知识/题库/文档页。
- **最近练习时间线**：`el-timeline`，≥80 分蓝点、否则橙点。
- 生命周期：`onBeforeUnmount` 里 `bar.dispose()` 释放 ECharts 实例；监听 window resize 重绘。

## 2. Graph.vue（262 行）—— 知识图谱管理（最核心的页面）

布局：顶部工具栏（学科 chips + 搜索 + 连线/聚焦/刷新按钮）→ 左侧画布卡片（图例 + 统计 + 缩放按钮）→ 右侧详情/编辑面板。

### 数据流
`load()`：`GET /graph/full` → `filterBySubject` → `filterByKeyword` → 更新 `counts` 响应式统计 → `render()`（`graph.data(toG6Data(...))` + `fitView(30)` 留 30px 边距自适应）。

### 节点编辑（点节点 → 右侧面板）
- `openDetail(model)`：高亮 selected、过滤掉 `x/y` 两个技术字段后逐条展示属性；
- 可编辑字段按类型配置（`EDITABLE` 映射：概念可改名/学科/关键词/描述，卡点可改频次…），改完 `PUT /graph/node/{id}` 落 Neo4j；
- `removeNode`：`DELETE /graph/node/{id}`，二次确认用 `el-popconfirm`。

### 创建关系（连线模式）
`toggleLink` 进入 linking 状态（按钮变黄提示"点击目标节点"）→ 点第一个节点记为 `linkSource`（G6 `linksource` 橙圈态）→ 点第二个节点弹窗选关系类型（PREREQUISITE / HAS_QUESTION_TYPE / REQUIRES_PATH / COMMON_MISCONCEPTION）→ `POST /graph/edge`。

### 拖拽保存
`onNodeDragEnd`：`PUT /graph/node/{id}` 只传 `{x, y}`（后端 `SET n +=` 增量合并）——**教师摆好的图谱布局永久留在 Neo4j 里**。

## 3. Knowledge.vue（164 行）—— 知识管理（表格版 CRUD）

- `el-tabs` 切四种节点类型，学科下拉 + 关键词搜索调 `GET /graph/nodes` 分页接口；
- 列定义复用 `FORMS` 配置（同一配置驱动表格列和编辑表单项，加新字段只改一处）；
- 新建/编辑对话框：数字字段用 `el-input-number`、学科/难度用下拉，其余 textarea；保存区分 `POST /graph/node`（新建带 label）和 `PUT /graph/node/{id}`（编辑）；
- 删除走 `DELETE /graph/node/{id}` + 刷新。

## 4. QuestionBank.vue（140 行）—— 题库管理

- 列表 `GET /question/list`，学科 tag、难度 tag（易绿/中黄/难红）；
- 录入对话框：学科下拉（9 学科硬编码 `SUBJECTS`）、难度 radio-button、知识点/题型/题干/答案；知识点输入框 placeholder 提示"关联知识图谱中的概念名"，引导教师把题挂到图谱概念上；
- 保存区分 POST/PUT，删除 `el-popconfirm` 二次确认。

## 5. Document.vue（110 行）—— 教案管理

- 右上角选文档类型（课件/试卷/错题本）+ `el-upload` 上传（`:http-request="doUpload"` 自定义上传动作，手动组 `FormData` 发 `POST /document/upload`）；
- 列表展示标题/类型 tag/解析状态 tag/上传时间/操作；
- 状态映射三个小函数 `tagType/statusType/statusText` 用数组下标 `['待解析','解析中','已完成','失败'][s]`，与后端 0~3 状态码一一对应；
- `parse(row)`：`POST /document/parse/{id}`，成功后弹结果对话框，`prettyResult` computed 把 JSON 字符串格式化 2 空格缩进显示。

## 6. Analysis.vue（104 行）—— 学情分析

- **热力图**：`GET /analysis/class/heatmap` → ECharts heatmap，`visualMap` 橙→蓝渐变（text 写成 ['掌握','薄弱'] 配合 min/max），单元格显示百分数；
- **雷达图**：学生名单在右侧，点击切换 `GET /analysis/student/{id}/radar` 重绘五维雷达；默认选中第一个学生；
- 两个图表都监听 resize、卸载时 dispose。
