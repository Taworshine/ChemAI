# 07 · 前端：图谱渲染引擎（graphRender.js，186 行）

**教师端 Graph.vue 和学生端 GraphView.vue 共用此模块**——两端图谱视觉、交互完全一致，只有权限差异（教师可编辑）。导出 5 个部分：

## 1. 常量映射

```js
export const COLORS = { Concept: '#4a7dff', QuestionType: '#ff9a4d', ... }
export const TYPE_NAMES = { Concept: '概念', ... }        // 图例/详情中文名
export const REL_NAMES = { HAS_QUESTION_TYPE: '包含题型', ... }  // 悬停提示里的关系中文名
export const FIELD_NAMES = { id: '编号', name: '名称', ... }     // 详情面板属性名中文化
```

## 2. `NODE_BALL_STYLES` —— 3D 球体配色（四种类型各一组三色）

```js
const NODE_BALL_STYLES = {
  Concept:      { light: '#a8c0ff', dark: '#3a66e0', stroke: '#2c4fb0' },
  ...
}
```
`light` 是受光面颜色、`dark` 是背光面颜色、`stroke` 是同色系深色描边。

## 3. `toG6Data(allNodes, allEdges)` —— 数据转换

把后端 `/graph/full` 的 `{id, label, props}` 列表转成 G6 图数据：

- **节点**：`type: 'circle', size: 48`（用户要求全部圆形）；
- **3D 球体渐变**：`fill: 'r(0.35,0.3,0.95) 0:#a8c0ff 1:#3a66e0'`——G6 v4 的径向渐变语法：圆心在 (0.35, 0.3)（左上偏）、半径 0.95，0% 处亮色 → 100% 处暗色，形成"左上受光"的球体感；
- **阴影**：`shadowBlur: 12, shadowOffsetY: 4`，让球"浮"在画布上；
- **坐标**：优先用 Neo4j 存的 `props.x/y`（种子数据带坐标、教师拖拽后回存），否则随机散布；
- **label**：`position: 'bottom'`，名称取 `props.name || description`；
- **每个节点自带 `stateStyles`**：hover/selected 用同色系深色描边——**从机制上杜绝了"点击变白"**（白边是旧版 `stroke:'#ffffff'` 基础描边造成的）；
- **边**：`type: 'quadratic'` 平滑曲线 + 三角形箭头，浅灰蓝 `#c3cde4`，只保留两端节点都在当前数据集里的边。

## 4. 过滤与"渐进展开"函数

- `filterBySubject(nodes, edges, subject)`：Concept/QuestionType 按 `props.subject` 过滤；ThinkingPath/Misconception 没有学科属性，**通过"跟随上游"规则保留**——遍历边，凡 source 被保留就把 target 也留下。切到"政治"仍能看到市场经济→题型→路径/卡点的完整子图。
- `filterByKeyword`：`JSON.stringify(n.props).includes(keyword)` 全属性模糊匹配（含描述、例题），命中的节点连同两端都在命中集里的边一起返回。
- `CORE_TYPES = ['Concept']`：**概念是知识骨架**，画布初始只显示概念节点（"最关键的几个点"）。
- `computeVisible(allNodes, allEdges, expandedIds)`：由展开状态推导可见子图——`可见 = 核心节点 ∪ 每个已展开节点的 1 跳邻居`；同时返回 `hiddenCount: Map<节点id, 隐藏邻居数>`，供 `+N` 徽标使用。**可见集是纯推导出来的**，收起 = 从 expandedIds 删掉 id，没有任何节点状态残留问题。
- `expandPathTo(allEdges, visibleIds, target)`：详情面板里点击"相关节点"时，若目标还在收起区，找到它与可见区之间的端点并展开（`ensureVisible`），把节点带进画布后再 focusItem。
- `toG6Data` 第三个参数接收 hiddenCount Map：有隐藏邻居的节点名字后追加 ` +N`（如"氧化还原反应 +4"），提示可展开。

## 5. `createGraph(container, hooks)` —— 交互引擎

### 行为模式
`drag-node / drag-canvas / zoom-canvas` + tooltip（悬停显示节点类型·学科·描述，或关系中文名）。
**注意没有 `activate-relations`**——那是旧版"悬停全场变白"的元凶，已移除。

### 全局状态样式
`hover`（加深阴影）、`selected`（深蓝细环 `#263b7a`）、`linksource`（连线模式下源节点橙圈）、`faded`（聚焦模式下 `opacity: 0.15`）。

### 自定义悬停（上浮效果）
```js
graph.on('node:mouseenter', e => {
  graph.updateItem(item, { size: model.size + 6,
    style: { shadowBlur: 26, shadowOffsetY: 7, ... } })
  item.getEdges().forEach(edge => graph.setItemState(edge, 'hover', true))
})
graph.on('node:mouseleave', e => { ...恢复 size-6 和原阴影... })
```
悬停节点放大 6px + 阴影加深（视觉上的"上浮"），相连的边变蓝加粗，**其他节点完全不动**。

### 聚焦模式（默认关闭）
- `graph.setFocusMode(on)`：关闭时清除所有 `faded` 状态；
- 开启后 `node:click`：以点击节点 + 其邻居为保留集，其余节点置 `faded`（浅灰低透明，不是白色），无关边也淡出；
- `canvas:click`（点空白）还原。两个页面各有一个 `focusOn` ref 绑定工具栏按钮文字"聚焦模式 / 聚焦中"。

### 事件钩子
`hooks.onNodeClick / onEdgeClick / onNodeDragEnd` 由调用方（两个视图）传入：教师端用来打开编辑面板/连线选目标/拖拽保存坐标；学生端用来打开详情面板。聚焦模式逻辑与业务钩子互不影响（G6 允许同一事件挂多个监听）。

## 6. 两端视图的展开/收起交互（学生 GraphView.vue / 教师 Graph.vue 共用同一套）

- 各持一个 `let expanded = new Set()`；点击节点：`expanded.has(id) ? 删除 : 加入`，然后 `render()` 重算可见子图并重新选中/聚焦该节点。
- 工具栏提供 **展开全部**（把所有 id 塞进集合）/ **收起全部**（清空集合）两个按钮。
- 顶部统计改为 `可见 X / 共 Y 个节点`——`counts` ref 在 render 时同步赋值。
- 搜索关键词激活时**绕过展开机制**直接全量显示命中集（找东西时不希望被折叠挡住）。
- 教师端例外：连线模式下点击仍优先走"选起点/选终点"逻辑，不与展开冲突；删除节点时同步 `expanded.delete(id)`。

## 7. 一个修复过的 bug 记录

右上角"N 个节点 · M 条关系"统计最初写成 `computed(() => allNodes.length...)`，但 `allNodes` 是普通数组（非响应式），所以永远显示 0。修复：两个视图各加 `const counts = ref({nodes:0, total:0, edges:0})`，`render()` 后手动赋值，模板改读 `counts`。
