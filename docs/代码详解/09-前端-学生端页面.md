# 09 · 前端：学生端页面

## 1. GraphView.vue（200 行）—— 知识图谱（只读探索版）

与教师端 Graph.vue 共用 `graphRender.js`，差异在交互定位：

- **无编辑能力**：没有连线/保存/删除按钮，点击节点只打开详情；
- **详情面板**：属性列表下方有"与「X」相关"列表——`related` computed 遍历当前边集，把与选中节点相连的邻居（带关系中文名，"属于"表示反向边）列出来；
- **定位飞行**：点相关项 `focusNode(id)`：`graph.findById` 找到目标 → 清掉旧 selected、置新 selected → `graph.focusItem(item, true, {easing:'easeCubic', duration:400})` 平滑飞过去——把"看邻居"做成了真正的图导航；
- 同样有学科 chips、搜索、聚焦模式开关和响应式统计（`counts` ref）。

## 2. Chat.vue（184 行）—— AI 智能追问

布局：左侧会话列表（新会话按钮 + 会话卡片显示 summary）+ 右侧聊天气泡区（banner / 消息流 / 输入栏）。

### 会话管理
`loadSessions()` / `newSession()` / `openSession(id)` 对应后端 `/agent/sessions|session|history/{id}`。挂载时优先打开最近会话，没有就自动建一个。

### SSE 流式接收（全前端唯一不用 axios 的地方）
```js
const resp = await fetch('/api/agent/chat', {
  headers: { 'Content-Type': 'application/json', satoken: localStorage.getItem('satoken') },
  body: JSON.stringify({ sessionId, message: text })
})
const reader = resp.body.getReader()
```
- `TextDecoder` 按流解码，按 `\n\n` 切 SSE 事件块，再解析每块的 `event:` 和 `data:` 行；
- `event: message` → 追加到 `streaming` 实现打字机效果（配闪烁光标 `▍`）；
- `event: error` → ElMessage 报错；
- 流结束后 `openSession()` 重新拉历史（拿到落库的完整消息 + 卡点标签），会话列表刷新 summary。

### 展示细节
AI 气泡里 `misconceptionType` 显示为"卡点：概念不清/计算错误/逻辑错误"的中文 tag；用户消息右对齐渐变蓝气泡、AI 左对齐灰气泡。

## 3. Practice.vue（161 行）—— 在线练习

三段式界面状态机：选学科 → 答题 → 结果。

- **选学科**：9 学科彩色卡片网格（`SUBJECTS_COLORS` 每科一个渐变），点击 `GET /practice/questions?subject=&count=5` 抽题；该科无题时提示"通知老师录入"；
- **答题**：每题 textarea 记录到 `answers[qid]`；底部进度条 `donePercent`（已作答数/总题数），全部作答才能点提交（`allAnswered`）；
- **判分**：`POST /practice/submit` 携带 `{subject, answers:[{questionId, userAnswer}]}`；**不经过前端判分，对错完全由后端说了算**；
- **结果页**：SVG 环形得分（`stroke-dasharray` 按比例显示渐变弧）、鼓励语按正确率分档、逐题回顾（对/错图标 + 我的答案 + 错题显示参考答案）。

## 4. Profile.vue（137 行）—— 学情报告

四张卡片：
1. **五维能力雷达**：`GET /analysis/student/{userId}/radar`，userId 取自登录时存的 localStorage——学生只能看自己的报告（后端也只按 token 身份查）；
2. **概念掌握度**：解析同一响应里的 `conceptMastery` JSON，进度条按 ≥80% 蓝 / ≥60% 橙 / 其余红 三档配色；
3. **练习历史**：`GET /practice/records`，"查看"按钮把 `row.detail` JSON 解析成逐题明细弹窗；
4. **错题记录（卡点）**：遍历自己所有会话 `GET /agent/history/{id}`，过滤出 AI 消息里 `misconceptionType` 非空的条目汇总展示——**对话中 AI 检测到的卡点自动沉淀成错题本**。
