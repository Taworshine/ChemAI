# 02 · 后端：认证与系统层

## 1. SysUser.java（76 行）—— 用户实体

- `@TableName("sys_user")` 绑定 MySQL 表。
- 字段：`id`（自增主键）、`username`（登录账号/学号）、`password`（**SHA-256 摘要，非明文**）、`realName`、`role`（`TEACHER` / `STUDENT`）、`className`、`createTime`。
- 纯 POJO：注解 + 字段 + getter/setter。密码注释里写明"演示项目，生产应使用 BCrypt + 盐"。

## 2. UserMapper.java（9 行）—— 用户表访问接口

```java
public interface UserMapper extends BaseMapper<SysUser> { }
```

继承 MyBatis-Plus 的 `BaseMapper` 即免费获得 `selectById / selectOne / insert / updateById / deleteById` 等全部基础 CRUD，本项目不需要自定义 SQL 所以是空接口。本项目其余 6 个 Mapper 结构完全相同，后文不再重复展开。

## 3. AuthController.java（78 行）—— `/api/auth` 登录认证

### 密码哈希 `sha256()`
`MessageDigest.getInstance("SHA-256")` 对密码字节做摘要，逐字节格式化成两位十六进制拼成 64 位字符串。**种子数据 `seed_mysql.sql` 里存的就是 `sha256("123456")` 的结果**，所以登录比对才能匹配。

### `POST /api/auth/login`
```java
SysUser user = userMapper.selectOne(new QueryWrapper<SysUser>().eq("username", username));
if (user == null || !user.getPassword().equals(sha256(password))) {
    return Result.error(401, "用户名或密码错误");
}
StpUtil.login(user.getId());
```
1. 按用户名查 MySQL；
2. 用户不存在 **或** 摘要不匹配都返回 `401`（不区分"用户不存在"和"密码错"，防止枚举账号）；
3. `StpUtil.login(userId)` 让 sa-token 生成令牌并建立会话；
4. 返回 `{token, role, realName, userId}` —— 前端把四项全部存进 `localStorage`（分别用于带请求头、路由分流、显示名字、查个人学情）。

### `GET /api/auth/info`
`StpUtil.getLoginIdAsLong()` 从当前请求的 token 反解出 userId，再查库返回当前用户信息。Layout.vue 挂载时调用它刷新顶栏名字。

### `POST /api/auth/logout`
`StpUtil.logout()` 销毁当前会话，前端随后清 localStorage 跳回登录页。
